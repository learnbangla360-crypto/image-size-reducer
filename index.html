    Step-by-step guide to reducing image size

    1. Add your images

    Drag photos onto the dashed box, or tap it to open your file picker. On a phone you can choose from your gallery. Files that aren't JPG, PNG or WebP, or that are over 50 MB, are skipped with a message so you know why.

    2. Set a width and height

    Modern phone photos are often 4000 pixels wide or more, far bigger than any screen needs. Entering 1600 as the width can cut a file dramatically with little visible change on a normal display. Keep Lock aspect ratio ticked and fill in just one box, and the other follows. Untick it to set width and height separately. Images are never enlarged.

    3. Or set a target size

    If you have a strict limit, such as 100 KB for a form, type it in the target box and pick KB or MB. The tool searches for the best JPEG or WebP quality that fits, and shrinks the pixels a little if it has to.

    4. Pick an output format

    "Same as original" keeps JPG as JPG, PNG as PNG and WebP as WebP. Choose JPEG for the widest compatibility, or WebP for smaller files on modern browsers. Photos with a lot of color and detail shrink best as JPEG or WebP. For a dedicated converter, see Image to WebP.

    5. Reduce and download

    Click Reduce Size. Each card shows the old size, the new size, the new dimensions and the percentage saved. Download files one at a time, or use Download all. Use Reset to clear everything and start fresh.

    Tips for best results

    • Change one setting at a time so you know what caused the difference.
    • Always keep your original file. Lossy compression can't be undone.
    • Reduce from the original, not from an already reduced copy.

    Expert tips and common mistakes

    Resize first, then set a target size

    Dropping the pixel count usually saves more than heavier compression does, and it hurts the look less. A 4000 px photo shown in a 800 px wide column is carrying a lot of pixels nobody sees.

    Don't expect much from PNG at the same format

    PNG is lossless, so compression alone can't shrink it much. Screenshots and logos are better kept as PNG, but photos saved as PNG are often huge. Switching those to JPEG or WebP is where the big savings are. If you need a plain converter, try PNG to JPG.

    Avoid reducing the same file repeatedly

    Every lossy pass adds more artifacts. Go back to the original each time you want a different size.

    Watch text and sharp edges

    Screenshots with small text show ringing around letters at low JPEG quality. Keep that file as PNG, or use a larger target size.

    Set the target a little under the limit

    If a form says 200 KB maximum, aim for 190. Some systems count a kilobyte as 1,000 bytes rather than 1,024.

    Crop before you shrink

    Removing dead space cuts pixels for free. Try the Crop Image tool first if your photo has a lot of empty background.

    Troubleshooting

    • The file got bigger or didn't change. It was probably already well compressed. The tool keeps your original in that case. Try a smaller width and height, a target size, or switch the format to WebP.
    • My PNG barely shrank. PNG is lossless. Set the output format to JPEG or WebP, or lower the width and height.
    • The result looks blurry or blocky. Increase the target size or use a larger width and height.
    • My transparent background turned white. JPEG doesn't support transparency. Choose WebP or keep PNG.
    • The target size wasn't reached. Very small targets may be out of reach for large, detailed images. Set a width such as 800 px and try again.
    • A file was skipped. It's either not a JPG, PNG or WebP, it's over 50 MB, or it's corrupted. Re-export it from the source and try again.
    • The page freezes with huge photos. Browsers can run out of memory on very large images. Reduce a few at a time and set a smaller width and height.
    • Download all only saved some files. Your browser may block multiple downloads. Allow them for this site or download each file individually.

    Glossary

    • Lossy compression: a method that discards some detail to make files smaller. JPEG is the best-known example.
    • Lossless compression: a method that shrinks a file without discarding any image data, as PNG does.
    • Resolution: the width and height of an image in pixels.
    • Aspect ratio: the proportion between an image's width and height.
    • EXIF: metadata stored in photos, such as camera model, date and sometimes location.
    • Canvas: the browser drawing surface this tool uses to re-encode images, described in the MDN toBlob documentation.

    It depends on the photo and the settings. Large camera JPGs often shrink a lot at quality 70 to 80, especially if you also lower the pixel dimensions. Images that were already compressed hard may barely change. The results list shows the exact before and after size for every file.

    Will I lose quality when I reduce image size?

    JPG and WebP output is lossy, so some detail is discarded. At quality 75 to 85 most people can't see a difference on screen. PNG output stays lossless, so it only gets smaller if you lower the dimensions or switch the format to WebP or JPEG.

    How do I reduce an image to a specific size like 100 KB?

    Type 100 in the Target size box and click Reduce Size. The tool lowers the quality step by step until the file fits. If quality alone can't get there, it also shrinks the pixel dimensions a little at a time. Very small targets can make the image look soft.

    Does it work on my phone?

    Yes. The layout is built for small screens, the buttons are large enough to tap, and you can pick photos straight from your gallery or camera roll. Very large photos can be slow on older phones, so try a smaller max dimension if the page struggles.

    Can I use it offline?

    Once the page has loaded, yes. All the logic is inside the page and it doesn't fetch anything while it works, so you can switch to airplane mode and keep reducing images. You'll need a connection to open the page the first time.

    What's the difference between reducing size and resizing?

    Reducing file size changes how many bytes the file takes up. Resizing changes the pixel width and height. They're linked, because fewer pixels usually means fewer bytes. This tool does both, so you can set exact width and height, or a target size in KB.

    Does the reduced image keep its EXIF data?

    No. The photo is redrawn on a canvas and saved as a new file, so camera details, timestamps and GPS location aren't carried over. That's handy for privacy and also trims a few kilobytes. If you need the metadata, keep your original file.
